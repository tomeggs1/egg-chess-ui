Border scale is the knob to judge first. At 1.00× the band is 29px, which against a 420px dialog is 7% of the width per side. Below about 0.6× the masonry stops reading as blocks; above 1.2× the corners start to crowd a small dialog.

Tile vs stretch. Tiling holds the block size constant and lets the count change with the dialog — the seams measured 5–8/255, so they do not show. Stretching keeps a fixed number of blocks and distorts them; drag the width with tiling off to see how quickly that reads as wrong.

Watch the corners as the dialog shrinks. The corner elbows are 49–53px wide and 53–68px tall at 1×. Two of them plus a little edge is already ~110px, so a narrow dialog becomes almost entirely corner. That is the constraint that decides the minimum usable dialog size, not the band thickness.
